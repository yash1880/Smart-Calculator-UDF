# Smart-Calculator-UDF
A simple and elegant **Smart Calculator** built using **HTML, CSS, and JavaScript**.  
It performs arithmetic operations, finds squares & cubes, calculates factorials, and checks even or odd numbers — all in one page.

---

## 🚀 Features

- ➕ **Arithmetic Calculator** – Add, subtract, multiply, divide, and modulus  
- 🟦 **Square & Cube Finder** – Get both results instantly  
- 🧩 **Factorial Calculator** – Uses recursion for accurate factorials  
- 🔢 **Even / Odd Checker** – Instantly identifies even or odd numbers  
- 🎨 **Beautiful UI** – Soft colors, shadows, and smooth fade animations  
- 📱 **Responsive Layout** – Works well on both desktop and mobile  

---

## 🧠 How It Works

1. Enter numbers into the input fields.  
2. Select an operation or calculator type.  
3. Click **Calculate / Find / Check**.  
4. The animated result appears instantly below the button.
